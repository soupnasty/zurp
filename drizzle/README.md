# ⚠️ These migrations are NOT applied — the DB is managed with `db:push`

This project's Neon database is managed by diffing `src/db/schema.ts`
directly against the live database:

```bash
npm run db:push
```

The SQL files in this directory were generated by `drizzle-kit generate`
but have **never been run through `drizzle-kit migrate`**, and the database
has no `__drizzle_migrations` bookkeeping table. In particular,
`0001_naive_mockingbird.sql` contains tables that already exist in the
database (created by earlier `db:push` runs), so:

**Do not run `npm run db:migrate` against the production database — it
will fail on `CREATE TABLE` statements for existing tables.**

Treat these files as historical documentation of schema changes only. If
the project ever moves to a real migration workflow, the history must be
baselined first (mark existing migrations as applied, or regenerate from
a clean snapshot).
