Semantic usage
Each accent color has a specific meaning in the simulation engine. Follow these consistently.
Cyan — Interactive / Brand
CTAs, links, navigation, brand logo, badges, section labels
zurp your card →
Blue — Points / Data

Credits, lounge access, insurance, perks

Red — Fees & costs
Annual fees, negative values, losses
−$795
Green — Net positive / Best
Best fit card (#1 only), net value of top card, success states, savings callout
+$1,273
Color rules
Green net value
Only the #1 ranked card gets green on its net value. All other rows use text-secondary.
Card names in headlines
Card names use text-primary (white) in personalized headlines. Only the savings amount gets green.

07
Effects & texture
Subtle layering that gives the interface depth without distraction.
Noise overlay
SVG fractalNoise at 0.03 opacity, fixed position, covers entire viewport. Adds tactile grain.
Ambient glow
800px radial gradients at ~0.4 opacity, blur(120px). Blue top-left, cyan bottom-right.
Nav blur
backdrop-filter: blur(20px) with rgba(10,14,23,0.8) background on fixed nav.
Top edge glow
1px gradient bar on card top edge. Creates a subtle light source effect.
Locked blur
opacity: 0.3 on row, filter: blur(5px) on text, user-select: none. For gated content.
Entry animation
fadeUp: translateY(20px) → 0 with staggered delays (0.1s increments). Ease timing.
